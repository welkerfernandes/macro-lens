# Fontes e proveniência

Fonte: World Bank Indicators API, https://data.worldbank.org/. Consulte os termos e metadados de cada indicador: https://www.worldbank.org/en/about/legal/terms-of-use-for-datasets. Dados e unidades pertencem às respectivas fontes; a licença do código não substitui condições de uso dos datasets.

Documentação técnica: https://datahelpdesk.worldbank.org/knowledgebase/articles/889392-about-the-indicators-api-documentation

Uma consulta live registra URL de origem, instante de obtenção, hash do conteúdo decodificado
e indicação de cache. O retrieved_at permanece o da obtenção original em cache hits.
O modo demo usa fixtures sintéticas e não deve ser citado como dado real.
O repositório não inclui payloads reais de empresas ou séries coletadas durante testes manuais.
